# SanzzDream Solutions MVP Operations

## 1. Website Purpose

The website is the public launch page for SanzzDream Solutions. It explains the four current services, starting packages, delivery estimates, revision policy, manual payment workflow, and how clients can start through Tally or WhatsApp.

## 2. Tally Form Purpose

Tally is the main intake form. Use it to collect:

- Name
- WhatsApp number
- Service needed
- Deadline
- Budget range
- Reference links/files
- Required output format

## 3. WhatsApp Contact Flow

WhatsApp is the fastest discussion channel for new leads and follow-ups.

1. Client clicks a WhatsApp CTA from the website.
2. Client sends a prefilled service-specific message.
3. SDS asks for missing details, references, deadline, and budget range.
4. SDS sends a quote only after scope is understood.

## 5. 50% Advance Rule

1. Client submits requirement through Tally or WhatsApp.
2. SDS reviews scope, deadline, deliverables, and revision count.
3. SDS sends price and delivery estimate.
4. Client pays 50% advance through UPI or bank transfer.
5. SDS confirms payment manually and starts work.

## 6. 50% Final Payment Rule

1. SDS shares draft or preview output.
2. Client requests included revisions if needed.
3. SDS completes valid revisions.
4. Client pays the remaining 50%.
5. SDS delivers final files, source files, or editable assets based on agreement.

## 10. Revision Policy

- Basic: 1 revision included
- Standard: 2 revisions included
- Premium: 3 revisions included
- Extra revisions: chargeable based on effort and scope

Major scope changes are not normal revisions. New requirements after quote may require extra cost.

## 11. Delivery Timeline Estimates

- Photo Editing: 1-2 days for simple edits
- Video Editing: 1-3 days for reels, shorts, and basic promos
- Data Analytics: 2-5 days depending on data size and dashboard complexity
- Frontend Development: 3-7 days depending on page count and design complexity

Urgent delivery may be possible depending on workload and may cost extra.

## 12. Cancellation / Refund Note

Cancellation terms depend on how much work has already been completed. Advance may not be fully refundable once work begins because execution time may already be assigned.

## 16. Phase 1 Website Features

The website contains the following key interactive elements to improve conversion rates and trust:

1. **Price Calculator**: Interactive frontend module letting users configure requirements across all 7 services.
2. **WhatsApp Quote Generator**: Encodes selected options into a prefilled quote request message.
3. **Demo Work Showcase**: Unique graphic previews for each service block, clearly marked "Mock / Demo".
4. **Payment Confirmation Form CTA**: Action item to submit manual transaction logs (UTR / Screenshot) to trigger admin check.
5. **Tally Intake Checklist**: Guided form instructions shown beforehand to help clients prepare required details.

## 17. Payment Confirmation Workflow

To track manual payments efficiently during the MVP stage, the following flow is used:
1. **SDS sends quote**: After discussing requirements on WhatsApp.
2. **Client pays 50% advance**: Through manual bank transfer or UPI.
3. **Client submits payment confirmation**: Direct submission through the external confirmation form (Tally/Google Form) or WhatsApp.
4. **SDS verifies payment manually**: Checking bank statement or UPI app.
5. **SDS updates Notion status to Advance Paid**: In the master project board.
6. **SDS assigns work**: Project moves to "Assigned" or "In Progress".

## 18. Quote Calculator Rule

The website estimate is not final. Final quote is confirmed only after SDS reviews the actual requirements, files, deadlines, and complexity.
